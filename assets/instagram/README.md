# Instagram archive

Full post archive for @4estfilms, @strungfilm and @hnimfilm, pulled
2026-08-01. 79 posts, 239 media files (232 images at 1080×1350, 7 videos).

`manifest.json` is the index — every post with its caption, permalink,
like/comment counts, and local filenames. Files are named
`<date>_<shortcode>_<n>.<ext>` so they sort chronologically.

These are committed rather than hot-linked because Instagram's CDN URLs
are signed and expire within hours.

Content is 4est Films' own work. Photographers credited in captions
include Forrest Wasko, Julian McPherson, and DP Aaron Berger (HNIM) /
Alexander C. Shields (Strung) — credit them if stills are used publicly.
