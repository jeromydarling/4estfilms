# Instagram archive

Everything published on @4estfilms, @strungfilm and @hnimfilm, pulled
2026-08-01. Instagram CDN URLs are signed and expire within hours, so the
media is committed rather than hot-linked.

## Grid posts — 79 posts, 239 files

`manifest.json` indexes every post: caption, permalink, like/comment
counts, and local filenames. Files are `<date>_<shortcode>_<n>.<ext>` so
they sort chronologically.

| Account | Posts | Range |
|---|---|---|
| 4estfilms | 37 | 2019-07-09 → 2023-12-22 |
| strungfilm | 26 | 2019-07-17 → 2021-07-27 |
| hnimfilm | 16 | 2023-11-10 → 2023-12-22 |

## Highlights — 207 items

**`hnimfilm/highlights/Day_1` … `Day_9` is a complete day-by-day video
diary of the His Name is Michael shoot** (Nov 14–24, 2023), 184 items,
mostly video. This is the single richest asset in the repo.

| Highlight | Items |
|---|---|
| hnimfilm Day 1 / 2 / 3 | 14 / 24 / 28 |
| hnimfilm Day 4 / 5 / 6 | 21 / 24 / 12 |
| hnimfilm Day 7 / 8 / 9 | 21 / 21 / 19 |
| 4estfilms STRUNG | 23 |

Each highlight folder has an `_index.json` with per-item date, media type,
and any text overlay. @strungfilm has no highlights. No account had active
stories at capture time (all three last posted in 2023).

## Weight, and what this is not

383 MB total — 302 MB video, 80 MB images. Nothing exceeds GitHub's
100 MB per-file limit (largest is 12.9 MB).

**This is an archive, not a set of site assets.** Cloudflare Pages caps
individual files at 25 MB and penalises large builds, so the website must
use a curated, re-encoded subset — not this directory as-is.
